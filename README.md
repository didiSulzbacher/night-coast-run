# Night Coast Run

A retro pseudo-3D driving game in a single HTML file. No build step, no dependencies: open `index.html` in a browser.

## Modes
Endless run (with an oncoming lane and police roadblocks the longer you survive), time trial, rival race, slalom jump, big jump, bullseye jump, stunt show, demolition derby, getaway and hot pursuit.

## Features
- 7 vehicles with their own stats and abilities, plus garage upgrades bought with coins
- Power-ups, police chases, car damage and repair kits
- Side missions that pay out coins
- Weather: clear, rain, fog, snow or random

## Controls
| Action | Keys |
|---|---|
| Drive | Arrow keys or WASD |
| Drift | Tap brake or Ctrl while steering |
| Jump | Space or J |
| Nitro | Shift or N |
| Fire | F |
| Pause | P or Esc |

On touch screens, on-screen buttons appear automatically.

## Play online
Enable GitHub Pages (Settings, Pages, deploy from the `main` branch) and the game is served from `index.html`.

Progress, records and coins are saved in the browser's local storage.
